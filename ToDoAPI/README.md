# Todo API
REST API для управления проектами, колонками и задачами в стиле Trello / Asana с поддержкой пользователей и JWT-аутентификации.

Пет-проект создан для демонстрации навыков работы с **C#**, **ASP.NET Core**, **Entity Framework Core** и **SQL**.

## Технологии
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- JWT Authentication
- C#
- Swagger (OpenAPI)

## Структура проекта
```
- Controllers/         # API-контроллеры
- Data/                # DbContext
- DTOs/                # Объекты для передачи данных
- Models/              # Сущности базы данных
- Services/            # Бизнес-логика
- Program.cs
- appsettings.json
```

## Возможности
- Регистрация и аутентификация пользователей (JWT)
- Управление проектами пользователя (создание, редактирование, удаление)
- Колонки внутри проекта (с порядком отображения)
- Задачи внутри колонок (с порядком)
- Перемещение задач между колонками
- Частичное обновление задач
- Фильтрация задач по колонке, проекту и статусу выполнения
- Пагинация
- DTO + Service-слой
- Seed-данные при первом запуске
- Асинхронная работа с базой данных

## Запуск
1. Клонировать репозиторий
2. Открыть решение в Visual Studio
3. Нажать F5

После запуска откроется Swagger UI.
При первом запуске автоматически создаётся база данных и добавляются тестовые данные (проект + колонки + задачи).
Также создается тестовый пользователь:
- Email: test@example.com
- Password: password123

# Аутентификация
- Зарегистрируйте нового пользователя (POST /api/auth/register) или войдите как существующий (POST /api/auth/login).
- Скопируйте token из ответа.
- В Swagger нажмите кнопку Authorize и введите скопированный токен.
- После этого все защищённые endpoints будут доступны.

# API Endpoints

## Аутентификация
| Метод | URL | Описание | Авторизация |
| :--- | :---: | :--- | :--- |
| POST | /api/auth/register | Регистрация | Нет |
| POST | /api/auth/login | Вход | Нет |

## Проекты
| Метод | URL | Описание |
| :--- | :---: | :--- |
| GET | /api/projects | Список проектов |
| GET | /api/projects/id | Проект с колонками и задачами |
| POST | /api/projects | Создать проект |
| PUT | /api/projects/id | Обновить проект |
| DELETE | /api/projects/id | Удалить проект |

## Колонки
| Метод | URL | Описание |
| :--- | :---: | :--- |
| GET | /api/columns/by-project/projectId | Колонки проекта |
| GET | /api/columns/id | Колонка с задачами |
| POST | /api/columns | Создать колонку |
| PUT | /api/columns/id | Обновить колонку |
| DELETE | /api/columns/id | Удалить колонку |

## Задачи
| Метод | URL | Описание |
| :--- | :---: | :--- |
| GET | /api/todos | Список задач (с фильтрами и пагинацией) |
| GET | /api/todos/id | Получить задачу |
| POST | /api/todos | Создать задачу |
| PUT | /api/todos/id | Обновить задачу / переместить в другую колонку |
| PATCH | /api/todos/id/complete | Отметить задачу выполненной |
| DELETE | /api/todos/id | Удалить задачу |

## Примеры запросов

### Регистрация
`POST /api/auth/register`
```json
{
  "email": "user@example.com",
  "password": "123456",
  "displayName": "Имя пользователя"
}

### Создать проект
`POST /api/projects`
```json
{
  "title": "Мой проект",
  "description": "Описание проекта"
}
```

### Создать колонку
`POST /api/columns`
```json
{
  "title": "To Do",
  "projectId": 1,
  "order": 1
}
```

### Создать задачу
`POST /api/todos`
```json
{
  "title": "Купить молоко",
  "description": "В магазине у дома"
}
```

### Переместить задачу в другую колонку
`PUT /api/todos/{id}`
```
{
  "title": "Купить молоко (обновлено)",
  "description": "Придется идти завтра",
  "columnId": 2,
  "order": 1
}
```
